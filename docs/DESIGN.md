# PeanutMilk：V2 框架

## 视觉

所有页面铺满视口，采用黑白灰、深色背景、细边框、简洁排版与圆角控件。详情和受限高度下的作品信息提供内部滚动。导航固定在顶部，保留「街机 / 常规」模式选择与支持浏览器中的全屏按钮。

作品图保留原素材色彩；街机场景、角色与 UI 以黑白灰为主，展开的方块以金色强调状态。分类标志位于方块上；浮出卡片保持磨砂半透明材质，内部改为彩色的圆角应用图标、微缩界面和文稿。游戏图标错位铺开至预览边缘，分别以不同周期在原位轻浮动，小尺寸「进入」按钮保持透射感。作品册采用纵向 3D 弧形卡片流，中心正面、相邻 34°、远端 46°/50° 的柔和倾斜，结合渐进缩小与深度呈现完整正面。20px 外圆角、14px 内图圆角、柔和高光、浮层阴影与半透明翻页胶囊延续深色 iOS 质感。间距按透视后的投影计算，避免上下近卡变成细线。

## 页面与交互

- 首页：主体仅保留 PeanutMilk 与「开始」。标题复用常规集合的全屏粒子聚合 / 弥散，绘制层不受文字矩形限制。标题中心位于屏高约 45%，无箭头的「开始」按钮下移至约 68%，采用 iOS 玻璃胶囊、半透明模糊和边缘高光；手机和矮屏自适应。点击开始或页头导航后，标题弥散与按钮 / 背景淡出结束再进入目的页面。背景继续叠加 React Bits Particles 与 Noise：单色细粒子响应鼠标排斥和运动扩散，颗粒噪点、细扫描线与暗角形成屏幕纹理。顶部保留作品、Haoling 和模式控件。
- 模式：首页加载默认街机，不持久化到本地存储。仅在街机和常规集合列表点击右上角按钮时，页面随模式切换；直接打开两种列表时同步模式选中状态。其余页面只改变模式选择，保留当前路由、页面与动效。点击首页「开始」后按选择进入街机或常规集合；顶部「作品」直接进入常规集合，街机中的「常规浏览」选择常规模式并跳转集合页。
- 街机：全屏横向像素场景。左右键或 A / D 移动，空格、上方向键或 W 跳跃；小屏提供触控按钮。顶起或直接点击问号，方块变金色并显示对应类别标志，磨砂分类卡片在该方块上方浮出，页面保持在街机。卡片内部显示彩色内容预览，不再放大类别标志；游戏预览混合已有作品封面与未命名的装饰应用图标。点击「进入」才打开对应分类作品册；键盘聚焦此按钮后可按 Enter。各方块独立保存开关状态，三张卡片可同时保留；只有再次顶起或点击自身方块才收起那一张并恢复问号，触发其它方块不影响已展开卡片，点击空白和 Esc 也不收起。
- 常规集合：以类别标题的粒子聚合作为主视觉，游戏集合命名为 `Game Desgin`，背景漂浮低透明度的原创游戏符号。底部居中放置三个圆点及左右轻箭头，支持点击、滚轮和键盘切换分类。当前标题先弥散再聚合后续类别；进入集合、切换街机或其它离页导航也在退场完成后执行。具体作品继续在作品册和详情中展示。标题保留真实文本，减少动态效果或 Canvas 不可用时仍可阅读并直接切换。
- 作品册：每个未筛选类别提供六张卡片，沿纵向 3D 弯曲轨迹排列和翻转，使用深度、俯仰与缩放表现流动；卡背保留 PeanutMilk 标识。选中项同步更新项目名、类别、简短事实、标签、状态与「详情」。支持点选、滚轮、方向键、上下按钮及纵向滑动，也兼容横向滑动；Home / End 选择首尾作品。手机提供适配布局，游戏子类筛选后显示相应的三张卡片。
- 详情：项目事实、简短玩法资料、图库与来源链接。个人职责未提供时明确显示「待补充」。

作品册的返回目标独立于模式选择，依据最近进入的街机或常规集合入口记录；直接打开作品册深链时默认回到常规集合。详情返回作品册时保留当前项目和游戏子类筛选。

## CRT 实现

`arcade.js` 将像素场景绘制到 2D Canvas，`crt.js` 再通过 WebGL shader 进行桶形曲面变形、扫描线、栅格、微弱辉光、噪点与暗角处理。问号点击坐标和浮出卡片锚点使用与 shader 一致的曲面换算，保证画面与交互位置对应。

`CRT_CURVATURE` 控制曲率，当前值为 `0.105`。扫描线、栅格、噪点、暗角及辉光强度在 `FRAGMENT` 内独立调整。WebGL 不可用、创建失败或上下文丢失时，切换为 2D Canvas 加 CSS 扫描线与暗角；该降级没有真实曲面变形，游戏逻辑与分类入口仍然可用。

减少动态效果偏好会关闭页面过渡、卡片入场与粒子动画，并固定 CRT 噪点时间。常规集合的标题聚合结束后停止绘制循环，后台标签页暂停动画，离开时释放观察器和事件监听。离开街机页面时释放帧循环、观察器、事件监听与 WebGL 资源。

## 内容与可替换边界

`data.js` 提供实际作品，`content.js` 提供身份、类别、占位档案与查询函数。三类共十八条档案：游戏含两个真实项目与四个槽位，界面和其它类别各六个槽位。`extraSlots` 补足六张卡片布局所需的条目，全部明确标为「待补充」，不构成已经完成的项目。文案仅保留名称、关键词、必要事实和动作词；占位档案使用空简介、空正文。CatPoker / POKOR 的资料与图片来源见 `sources.md`，项目关联由用户提供，公开素材不能用来推断个人职责。

`app.js` 管理路由、模式选择、来源入口与作品册；`album-motion.js` 先按完整卡片流的高度确定基础尺寸，再将选中项放大 1.55 倍（低矮横屏 1.35 倍），向左上展开并保留相邻项原尺寸。投影间距在原基础上增加 50%；两端可自然离开舞台，在边缘淡出。连续可微曲线计算位置、景深、倾角、比例及明暗，以保留速度的临界阻尼响应连续输入；放大权重在中心和相邻位置的导数均为零，避免切换时尺寸突变。视点与主卡中心对齐，避免透视把相邻卡片推到近 90°。手势直接驱动当前位置，抬手后吸附；详情跟随最接近中心的卡片更新。循环只在完全透明的端点换位，透明度应用于卡面而不压平 3D 父层。低矮视口通过滚动保留足够的卡片大小。`style.css` 顶部变量控制黑白灰主题与页边距，`album-flow.css` 控制作品册的 3D 材质、透视与响应式排布。常规集合由 `work-collections.js` / `work-collections.css` 管理，标题粒子在 `title-particles.js` 中根据标题字形生成。

街机通过 `mountArcade(container, { onCategory, onExit })` 独立挂载与清理；`WORLD`、`PORTALS` 和 `update()` 分别管理场景、问号与运动逻辑。`arcade-cards.css` 独立控制磨砂分类卡片的尺寸、材质和入口按钮，不再接收项目封面预览配置。

首页动效独立于内容和街机，可在方案确定后替换。所有作品入口都可通过常规模式直接访问。项目无第三方运行依赖，构建输出可部署为静态站点。
