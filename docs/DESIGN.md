# PeanutMilk：V2 框架

## 2026-10-27：玻璃导航与作品详情

导航改为悬浮圆角深色玻璃容器，左侧为圆形 PM 头像标识，中间保留作品、分类与关于我，右侧为下载 PDF 与桌面全屏控制。手机保留主导航，展开后的作品分类另起一行。`site-header.js` / `site-header.css` 管理导航与 PDF 提示；PDF 目前仅显示「下载即将开放」，没有下载接口或文件，后续需接入单次下载 key 的后端。`--site-header-clearance` 为下方内容提供响应式避让。

所有项目详情使用 `project-detail.js` / `project-detail.css`，在现有内部滚动容器中展示连续作品长页，页尾提供返回作品册和回到顶部。详情顶部的黑色章节导航栏已移除，主视觉下方的探索按钮仍可滚动到项目简述。POKOR 按用户提供的 POKER 设计稿，依次展示主视觉、项目简述、浅色装饰框界面轮播、六角色与十六图标。界面轮播由真实按钮实现，可用左右方向键、Home / End、圆点和横向滑动切换，点击图片打开原生对话框大图。参考图中的菜单文字保留在原画内；它不是可运行游戏。

CatPoker 使用相同阅读结构与交互，保留自己的素材和深色视觉；没有角色或图标素材的项目不会生成空章节。待补充项目显示简洁的整理中状态，个人分工继续标记待补充。详情返回仍保留原项目与筛选参数。减少动态效果时禁用入场动画与平滑滚动，离页清理观察器、手势与滚动监听。

本次按用户两张参考图定向实现，不随机抽取替代风格。玻璃、圆角、装饰边框与浅色画面展示区为明确的设计要求。原图被拆成独立透明 WebP 素材，并非整张长图铺在页面中；图文布局与交互由真实 HTML/CSS/JS 实现。来源与裁剪信息见 `public/assets/games/pokor/portfolio/assets.json`。

## 视觉

所有页面铺满视口，采用黑白灰、深色背景、细边框、简洁排版与圆角控件。详情和受限高度下的作品信息提供内部滚动。导航固定在顶部，首页、街机列表与常规作品集合入口右下角提供「街机 / 常规」模式选择，页头保留浏览器中的全屏按钮。首页默认使用与街机列表一致的外框、曲面 shader 和 CRT 纹理。

作品图保留原素材色彩；街机场景、角色与 UI 以黑白灰为主，展开的方块以金色强调状态。分类标志位于方块上；浮出卡片保持磨砂半透明材质，内部改为彩色的圆角应用图标、微缩界面和文稿。游戏图标错位铺开至预览边缘，分别以不同周期在原位轻浮动，小尺寸「进入」按钮保持透射感。作品册采用纵向 3D 弧形卡片流，中心正面、相邻 34°、远端 46°/50° 的柔和倾斜，结合渐进缩小与深度呈现完整正面。20px 外圆角、14px 内图圆角、柔和高光、浮层阴影与半透明翻页胶囊延续深色 iOS 质感。间距按透视后的投影计算，避免上下近卡变成细线。

## 页面与交互

- 首页：主体保留 PeanutMilk 与「开始」。首次进入先播放约 900ms 的 CRT 开机扫描与亮线展开，完成后才启动标题聚合并浮现按钮。标题复用常规集合的全屏粒子聚合 / 弥散，绘制层不受文字矩形限制。标题中心位于屏高约 45%，无箭头的「开始」按钮位于约 68%，采用 iOS 玻璃胶囊、半透明模糊和边缘高光；手机和矮屏自适应。背景保留 React Bits Particles 的鼠标排斥与运动扩散；街机模式将背景与标题合成后应用 CRT，常规模式保留 Noise、细扫描线和暗角。顶部保留作品、关于我和全屏按钮，右下角提供模式开关。
- 模式：首页加载默认街机，不持久化到本地存储。模式开关显示在首页、街机与常规集合入口右下角；作品册、详情和关于我页面不显示。首页原地切模式保留 DOM、背景粒子与标题动画进度。点击「开始」后按选择进入街机或常规集合；街机首页与街机列表之间只播放约 460ms 的频道切换，外框持续存在。实际从普通显示进入 CRT 时播放开机，退出 CRT 时播放约 420ms 的扫描噪点与闪烁切出。常规首页离场保留标题弥散及按钮 / 背景淡出，期间的新导航或模式选择覆盖旧目标。
- 街机：全屏横向像素场景。左右键或 A / D 移动，空格、上方向键或 W 跳跃；小屏提供触控按钮。顶起或直接点击问号，方块变金色并显示对应类别标志，磨砂分类卡片在该方块上方浮出，页面保持在街机。卡片内部显示彩色内容预览，不再放大类别标志；游戏预览混合已有作品封面与未命名的装饰应用图标。点击「进入」才打开对应分类作品册；键盘聚焦此按钮后可按 Enter。各方块独立保存开关状态，三张卡片可同时保留；只有再次顶起或点击自身方块才收起那一张并恢复问号，触发其它方块不影响已展开卡片，点击空白和 Esc 也不收起。
- 常规集合：以类别标题的粒子聚合作为主视觉，游戏集合命名为 `Game Desgin`，背景漂浮低透明度的原创游戏符号。底部居中放置三个圆点及左右轻箭头，支持点击、滚轮和键盘切换分类。当前标题先弥散再聚合后续类别；进入集合、切换街机或其它离页导航也在退场完成后执行。具体作品继续在作品册和详情中展示。标题保留真实文本，减少动态效果或 Canvas 不可用时仍可阅读并直接切换。
- 作品册：每个未筛选类别提供六张卡片，沿纵向 3D 弯曲轨迹排列和翻转，使用深度、俯仰与缩放表现流动；卡背保留 PeanutMilk 标识。选中项同步更新项目名、类别、简短事实、标签、状态与「详情」。支持点选、滚轮、方向键、上下按钮及纵向滑动，也兼容横向滑动；Home / End 选择首尾作品。手机提供适配布局，游戏子类筛选后显示相应的三张卡片。
- 详情：项目事实、简短玩法资料、图库与来源链接。进入作品册或项目详情时，页头「作品」向右展开 iOS 风格的圆角抽屉，显示游戏、界面和其它项目分类；页面内不再重复放置类别导航。个人职责未提供时明确显示「待补充」。关于我页面承载个人介绍、邮箱、爱玩的游戏和 Steam 好友码，标题同样使用粒子字形。

`mode` 是唯一的用户模式选择，列表深链会同步该选择；显示控制器只记录实际已挂载的 CRT 状态，并据此决定信号动画。两者分别表示用户要什么与当前显示什么，待提交的新模式不能覆盖转场源状态。作品册的 `collectionOrigin` 独立记录最近进入的街机或常规集合入口；直接打开作品册深链时默认回到常规集合。详情返回作品册时保留当前项目和游戏子类筛选。

## CRT 实现

首页额外使用 `CRT_HOME_LENS = 0.28` 的内部镜头映射，放大中央画面并压缩边缘，但镜头权重在屏幕四边归零，因此物理玻璃形状与街机列表一致。首页鼠标坐标走相同映射；街机列表默认 lens 为 0，原角色和卡片命中坐标不变。屏内保留暗灰层次，黑白灰机壳通过 SVG / CSS 的多层柔和阴影、厚边斜面、凹槽与玻璃反光呈现圆润的凹入感。首页模式控件恢复原右下位置。

`crt.js` 的 `CRT_CORNER_RADIUS = 0.12` 定义源坐标圆角，统一 shader 玻璃遮罩、`crtScreenOutline()` 外框及过渡裁切。信号放在固定的 `.arcade-display__aperture` 内，边界向源图内收 0.008，避免亮线或闪光覆盖抗锯齿边缘；噪点和开机亮线居中，频道条带绕屏幕中心滚动。过渡仅让屏内画面明暗继承同一动画时钟，换页后不重新计时。

共享层级固定为 `--layer-display: 20`、`--layer-controls: 30`、`--layer-cards: 40`，页头为 `100`，使外框位于提示、按钮和分类卡片下方。首页与街机页面根不使用 `isolation: isolate`；分类无障碍导航仍由街机根管理，但放在会淡出的 `.pm-arcade__frame` 外，避免焦点入口随画面变暗。

首页与街机列表共用 `crt.js` 的 WebGL shader，进行桶形曲面变形、扫描线、栅格、微弱辉光、噪点与暗角处理。`arcade.js` 提供像素场景的 2D Canvas；`intro-screen.js` 合成首页背景粒子与标题画布作为另一种输入。背景和标题的同步 `onRender(canvas)` 回调确保在 WebGL 背景绘制缓冲被清除前捕获本帧；首页通过 `mapPointer(u, v)` 将交互坐标转换回曲面前的位置。街机问号点击坐标和浮出卡片锚点同样使用与 shader 一致的曲面换算。

`CRT_CURVATURE` 控制曲率，当前值为 `0.105`。扫描线、栅格、噪点、暗角及辉光强度在 `FRAGMENT` 内独立调整。WebGL 不可用、创建失败或上下文丢失时，切换为原有 Canvas / 文字层及 CSS 扫描线与暗角；该降级没有真实曲面变形，游戏逻辑与分类入口仍然可用。首页直接监听 CRT 上下文丢失，静态画面也会立即回退；CRT 销毁为幂等操作，并主动释放上下文，避免频繁切模式耗尽浏览器上下文额度。

减少动态效果偏好会立即完成显示切换、关闭卡片入场与粒子动画，并固定 CRT 噪点时间。首页使用 `rasterizeReducedMotion` 生成已聚合的静态标题画布供 CRT 合成，语义文字保留为回退；普通集合保留文字标题。常规集合的标题聚合结束后停止绘制循环，后台标签页暂停动画，离开时释放观察器和事件监听。首页与街机各自负责释放所属的绘制循环和资源，共享显示控制器负责取消旧信号计时器并合并连续导航。

## 内容与可替换边界

`data.js` 提供实际作品，`content.js` 提供身份、类别、占位档案与查询函数。三类共十八条档案：游戏含两个真实项目与四个槽位，界面和其它类别各六个槽位。`extraSlots` 补足六张卡片布局所需的条目，全部明确标为「待补充」，不构成已经完成的项目。文案仅保留名称、关键词、必要事实和动作词；占位档案使用空简介、空正文。CatPoker / POKOR 的资料与图片来源见 `sources.md`，项目关联由用户提供，公开素材不能用来推断个人职责。

`app.js` 管理路由、模式选择、来源入口与作品册；`album-motion.js` 先按完整卡片流的高度确定基础尺寸，再将选中项放大 1.55 倍（低矮横屏 1.35 倍），向左上展开并保留相邻项原尺寸。投影间距在原基础上增加 50%；两端可自然离开舞台，在边缘淡出。连续可微曲线计算位置、景深、倾角、比例及明暗，以保留速度的临界阻尼响应连续输入；放大权重在中心和相邻位置的导数均为零，避免切换时尺寸突变。视点与主卡中心对齐，避免透视把相邻卡片推到近 90°。手势直接驱动当前位置，抬手后吸附；详情跟随最接近中心的卡片更新。循环只在完全透明的端点换位，透明度应用于卡面而不压平 3D 父层。低矮视口通过滚动保留足够的卡片大小。`style.css` 顶部变量控制黑白灰主题与页边距，`album-flow.css` 控制作品册的 3D 材质、透视与响应式排布。常规集合由 `work-collections.js` / `work-collections.css` 管理，标题粒子在 `title-particles.js` 中根据标题字形生成。

街机通过 `mountArcade(container, { onCategory, modeMarkup })` 独立挂载与清理；`WORLD`、`PORTALS` 和 `update()` 分别管理场景、问号与运动逻辑。页面组件不调度开关机；`app.js` 统一调用 `createArcadeDisplay(main)` 的控制器，根据实际源显示与目标显示选择 `boot`、`channel` 或 `off`。`arcade-display.js` / `arcade-display.css` 持有共用外框与信号动画，`arcade-cards.css` 独立控制磨砂分类卡片的尺寸、材质和入口按钮。

首页通过 `mountIntroScreen()` 管理内容和粒子，向路由层暴露 `setArcade()`、`reveal()` 与普通显示的 `leave()`；内容生命周期与共享显示控制器分离，可独立替换。所有作品入口都可通过常规模式直接访问。项目无第三方运行依赖，构建输出可部署为静态站点。
